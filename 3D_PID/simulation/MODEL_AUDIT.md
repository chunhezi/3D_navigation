# 仿真模型检查记录

## 检查结论

先前默认仿真并不是从完整实物执行链路建立的已验证动力学模型。位置 PI 与参考生成器确实复用了原代码，但被控对象是新增的“理想力执行器 + 球体线性阻力”模型。其预测不能直接用于判断实物的 1.5 倍经验补偿是否正确。先前建议据此把实物系数改为 1.0，依据不足。

## 已核对的实现

- `motion_modes/motion_stabilize_3d.py`：位置误差进入原 PI，叠加重力前馈，随后调用 `force_3d_to_current`，实际输出为六路电流。
- `core/current_allocator.py` 与 `core/current_solver.py`：使用位置相关磁场矩阵、假设磁矩和伪逆求解电流；含 Fz 下限，电流可能限幅。期望力并不是独立测量的真实磁力。
- `core/magnetic_model.py/return_matrix`：将相机位置从 cm 转为 m，再用于磁场矩阵。仿真进入 PI 前乘 100、积分运动前使用 m，与这一单位约定一致。
- 原 PI 的增益、积分更新和参考推进顺序均直接复用；未发现可解释 0.837 cm 偏差的 cm/m 换算错误。
- 名义线性阻力采用 `update_fx` 的黏度表达式，未使用旧 `dynamic_position` 的另一套阻力值。黏度及阻力模型仍需辨识，不能视为实物真值。
- 用恒定加速度解析解、终端速度平衡和离散步长细分一致性验证了植物积分器。数值积分正确不等于被控对象模型正确。

## 旧模型为何恰好偏移约 0.837 cm

按源代码参数计算，理论净重力约 `33.466 µN`，期望前馈约 `50.199 µN`。旧模型把两者相减后直接施加于磁珠，制造出 `16.733 µN` 的恒定向上余力。

由于大误差下 Z 积分被冻结，固定点最终近似满足：

```text
Kp_z * error_z + (F_feedforward_z - W_effective) = 0
error_z = -16.733e-6 / 2e-5 ≈ -0.83665 cm
```

回归测试复现了这个固定点结果，因此偏差来源可以追溯到上述建模假设，而不是动画绘制问题。它并不能证明真实磁力存在相同的余量。缺少独立磁力或运动数据，不能仅从 1.5 系数推出执行器增益等于 2/3。

## 当前处理与边界

保留原结果在 `output/previous_ideal_force/`，并保留 `--plant-mode ideal_force` 以复现。默认采用明确标注的 `equilibrium` 工作点模型：假定当前前馈对应悬浮平衡指令，只对该指令附近的增量响应做位置控制仿真。原始 PI 和实物前馈参数保持不变。

新的曲线只是这一简化假设下的结果，不能因曲线重合就宣称实物模型已修复或验证。两种模式、平衡指令、物理净重力和“未辨识”状态均写入 `summary.json`，图和动图也显示模型名称。

下一步若要逼近真实响应，应使用带时间戳的实际位置、参考位置、期望力、下发/实测电流、有效测量标志、泵状态等日志，辨识工作点、三轴增量响应、阻尼和延迟；最好覆盖多个高度和小幅输入变化。现有源代码本身无法唯一确定这些实物参数。
